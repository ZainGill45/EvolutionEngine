# Design System

Evolution Engine has one visual language: hard edges, a monochrome dark palette, and depth built from tonal elevation and soft shadows. `src/index.css` is the source of truth for every token below.

## Principles

1. **Hard edges everywhere.** Nothing has a border radius: not components, images, inputs, focus rings or scrollbars.
2. **Monochrome only.** Every color has zero chroma. Errors and destructive actions are shown with contrast, weight, wording and icons, never with hue.
3. **Dark only.** There is no light theme and no theme switching.
4. **Depth comes from elevation.** Higher layers are lighter, carry a 1px highlight along their top edge, and cast a softer, larger shadow.

## Elevation

| Layer | Surface token | Shadow | Use |
| --- | --- | --- | --- |
| Sunken | `bg-sunken` | `shadow-sunken` | Inputs, wells, code blocks, scrollbar tracks |
| Base | `bg-background` | none | The application canvas |
| Raised | `bg-card` | `shadow-raised` | Cards, panels, sidebars |
| Overlay | `bg-popover` | `shadow-overlay` | Popovers, menus, dialogs, tooltips |
| Interactive | `bg-secondary`, `bg-muted`, `bg-accent` | none | Hover, selected and pressed fills |

## Text and lines

| Token | Use |
| --- | --- |
| `text-foreground` | Primary text |
| `text-muted-foreground` | Secondary text, labels, metadata |
| `bg-primary` / `text-primary-foreground` | The single most important action, shown as inverted light on dark |
| `text-destructive` | Errors and destructive actions |
| `border-border` | Hairline separators and outlines |
| `border-input` | Form control outlines |
| `ring-ring` | Focus indication |

## Enforcement

- The Tailwind theme resets the `color`, `radius` and `shadow` namespaces, so only the tokens above generate CSS. `shadcn/no-unknown-classes` reports anything else, such as `bg-red-500`, `rounded-xl` or `shadow-lg`.
- An ESLint `no-restricted-syntax` rule rejects any `rounded` utility in renderer code, including `rounded-none`, `rounded-full` and arbitrary values.
- A base-layer `border-radius: 0 !important` squares off native and third-party elements that bypass the class rules.

## Adding shadcn components

Components generated by the shadcn CLI arrive with the default styling. Before committing one:

1. Remove every `rounded-*` class.
2. Replace `shadow-xs`, `shadow-sm` and `shadow-md` with `shadow-raised`, and `shadow-lg` and above with `shadow-overlay`. Use `shadow-sunken` for inputs.
3. Replace any non-token color with the closest token from the tables above.
4. Run `npm run check`.
